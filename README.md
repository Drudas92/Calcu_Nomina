# Calcu_Nomina

## Sistema Inteligente de Gestión y Validación de Nómina

### Descripción

Calcu_Nomina es una aplicación de escritorio desarrollada en Python para calcular, validar y comparar desprendibles de nómina.

El proyecto nace con el objetivo de automatizar la validación de pagos, detectar diferencias entre el cálculo esperado y el desprendible entregado por la empresa y facilitar el análisis de novedades de nómina.

---

## Características principales

- Cálculo automático de salario.
- Cálculo de recargos.
- Validación de salud y pensión.
- Manejo de auxilio de transporte.
- Bono de asistencia configurable.
- Comparación de desprendibles PDF.
- Exportación de resultados a Excel.
- Historial de liquidaciones.
- Dashboard de estadísticas.
