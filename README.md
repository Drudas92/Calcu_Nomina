# Calcu_Nomina

**Sistema Inteligente de Gestión y Validación de Nómina**

## Descripción
**Calcu_Nomina** es una aplicación de escritorio desarrollada en Python como **proyecto formativo y académico**. Nace con el objetivo de aplicar conocimientos en desarrollo de software para automatizar el cálculo de nómina colombiana, facilitando la auditoría de desprendibles oficiales (BUK) y la validación de pagos reales en cuenta bancaria.

---

## Características Principales
- **Cálculo Quincenal Automático:** Liquidación de salario base, recargos nocturnos y dominicales/festivos habituales y no habituales.
- **Descuentos de Ley y Personales:** Deducciones automáticas de Salud (4%), Pensión (4%) y créditos personales (como Crédito Denario).
- **Módulo de Auditoría BUK vs Pago:** Comparación directa entre el cálculo propio, el desprendible reportado por la empresa y la consignación bancaria real para detectar inconsistencias.
- **Perfil de Usuario Persistente:** Gestión y guardado local de datos del empleado (Nombre, Cargo, Sueldo Base) mediante archivos JSON.
- **Distribución Portátil:** Empaquetado ejecutable (.exe) que no requiere instalación previa de Python.

---

## Tecnologías Utilizadas
- **Lenguaje:** Python 3.14
- **Interfaz Gráfica:** CustomTkinter
- **Persistencia de Datos:** JSON
- **Empaquetado:** PyInstaller
